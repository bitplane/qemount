# Research Unix V5/V6 Filesystem

The Fifth and Sixth Edition Research Unix filesystem is the PDP-11 predecessor
of the V7 layout. The 9front `v6fs` reader accepts raw disk images from both
editions and exposes them read-only.

## Structure

The format uses fixed 512-byte blocks. Block zero is reserved, the superblock
is block one, and the inode list begins at block two. Root is inode 1.

On-disk inodes are 32 bytes and contain eight 16-bit block addresses. Small
files use those addresses directly; large files use them as single-indirect
blocks. File sizes are 24-bit values split into an eight-bit high part and a
16-bit low part. Directory entries are 16 bytes: a little-endian 16-bit inode
number followed by a fixed 14-byte name.

The format has no magic number. Reliable identification requires structural
checks of the superblock, root inode and root directory rather than one fixed
signature. PDP-11 timestamps use word-swapped 32-bit ordering.
