# Research Unix V10 Filesystem

The Tenth Edition Research Unix filesystem retains the traditional Unix inode
and directory model while using fixed 4096-byte blocks. The 9front `v10fs`
reader mounts raw images read-only.

## Structure

The superblock is block one, the inode list starts in the following block, and
root is inode 2. Its 64-byte inode layout contains mode, ownership, 32-bit file
size, timestamps and 13 packed 24-bit block addresses. The first ten addresses
are direct blocks and the final three begin indirect ranges. Directory entries
remain 16 bytes with a 16-bit inode number and 14-byte name.

There is no unique filesystem magic. Detection therefore needs corroborating
checks across the superblock, root inode and root directory. The 4 KiB block
size distinguishes the V10 interpretation from the otherwise closely related
32V and V7 layouts.
