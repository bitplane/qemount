# UNIX/32V Filesystem

UNIX/32V brought the V7-era filesystem to the VAX. The same basic layout was
used by early Berkeley VAX systems before the Fast File System. 9front's
`32vfs` reads 512-byte 32V images and, when selected explicitly, 1024-byte
pre-FFS Berkeley images.

## Structure

The superblock is block one, the inode list follows it, and root is inode 2.
Inodes are 64 bytes with 13 packed 24-bit block addresses: ten direct and three
indirect roots. Directory entries are 16 bytes, containing a 16-bit inode
number and a fixed 14-byte name.

The 9front reader supports direct blocks and the single-indirect range. It
serves the image read-only.

Like the closely related V7 filesystem, 32V has no dedicated magic number.
Detection must combine plausible superblock bounds with inode and root-directory
validation, while accounting for the selected 512- or 1024-byte block size.
